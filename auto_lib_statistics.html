학교도서관 통계대장 자동계산

독서로DLS에서 내려받은 반출 파일을 업로드하고, DLS에 없는 항목(활용수업·행사·자원봉사·기타업무 등)만 직접 입력하면 나머지는 자동으로 계산되어 학교도서관 통계대장 서식 그대로 출력됩니다. 업로드한 파일과 입력한 내용은 서버로 전송되지 않고 이 브라우저 안에서만 처리됩니다.

1 데이터 입력

입력한 값은 이 브라우저에 자동 저장되어 새로고침해도 남습니다. 다른 PC로 옮기거나 백업하려면 "설정·입력값 저장(JSON)"으로 파일을 내려받고, 그 파일을 "불러오기"로 되돌리면 됩니다. 3월에 시작해 다음해 2월에 끝나는 학년도 단위로 입력·집계합니다. 학년도가 바뀌면 아래 월 목록도 자동으로 바뀝니다. 처음 사용해보신다면 "예시 데이터로 미리보기"를 눌러 동작을 먼저 확인해볼 수 있습니다. 학교·학년도에 상관없이 그대로 사용할 수 있으며, 입력한 내용은 "전체 초기화"로 언제든 지울 수 있습니다.

아래 4개는 각각 다른 화면에서 반출해야 하는 별개 파일입니다. 반출된 파일을 열어 고치지 말고 그대로 업로드하세요(엑셀 .xlsx만 지원).

① 소장자료 현황 — 단행본미입력
  1. DLS 상단 메뉴 통계 → 관리통계 → 자료분류
  2. 기간 단위를 월별로 선택 (시작·종료 월은 결과에 영향 없음 — 이 화면은 항상 지금 이 순간의 누적 소장수만 보여줍니다)
  3. 오른쪽 자료구분에서 단행본 선택 → 검색
  4. 표 아래 오른쪽 반출 버튼 클릭 → 파일 저장
② 소장자료 현황 — 비도서미입력
  1. DLS 상단 메뉴 통계 → 관리통계 → 자료분류
  2. 기간 단위를 월별로 선택 (시작·종료 월은 결과에 영향 없음 — 이 화면은 항상 지금 이 순간의 누적 소장수만 보여줍니다)
  3. 오른쪽 자료구분에서 비도서 선택 → 검색
  4. 표 아래 오른쪽 반출 버튼 클릭 → 파일 저장
③ 대출통계 — 이용자별미입력
  1. DLS 상단 메뉴 통계 → 대출통계 → 이용자별
  2. 기간을 월별로, 시작 3월 ~ 종료 이번 달
  3. 드롭다운을 기본값 "대출권수"에서 대출이용자수로 반드시 변경 → 검색
  4. 표 아래 오른쪽 반출 버튼 클릭 → 파일 저장
④ 대출통계 — 주제별미입력
  1. DLS 상단 메뉴 통계 → 대출통계 → 주제별
  2. 기간을 월별로, 시작 3월 ~ 종료 이번 달 → 검색
  3. 표 아래 오른쪽 반출 버튼 클릭 → 파일 저장

참고: 소장자료(관리통계) 파일은 "현재 시점의 누적 소장수"만 담겨 있고(기간을 아무리 넓게 잡아도 결과는 1개월치뿐), 지난달 것을 지금 다시 반출해도 지난달 값으로 되돌아가지 않습니다. 그래서 매달 빠짐없이 그 달에 반출해서 업로드해두는 것이 정확한 월별 기록을 남기는 유일한 방법입니다.

기타 메모

배율 두 칸은 환경설정에서 "월별 직접입력"을 골랐을 때만 쓰입니다(고정·미적용 모드에서는 입력해도 계산에 반영되지 않아 잠깁니다). 비고·내용·기타업무사항은 누적되지 않고 그 달 값만 출력에 표시됩니다.

배율(倍率, ratio — 관외 실측치에 곱해 관내 이용 규모를 추정하는 계수)을 어떻게 적용할지 정합니다. 여기서 정한 값은 입력값과 함께 자동 저장되고, "설정·입력값 저장(JSON)" 파일에도 같이 담깁니다.

관내 열람자 배율 (2. 이용자 현황)

관외 대출 인원수에 곱해 관내(열람자) 인원을 추정함. 미적용을 고르면 관내 칸이 모두 "-"로 나오고 합계는 관외 실측치만 반영됨. 월별 직접입력에서 그 달 값을 비워두면 위 기본 배율이 쓰임.

이용자료 관내추정 배율 (3. 이용자료 현황)

관외 대출 건수 합계에 곱해 관내 이용 건수를 추정함. 미적용이면 "관내" 칸이 "-"가 되고 합계는 관외대출 계와 같아짐.

누계는 통계대장 서식과 같이 달마다 그 달의 배율로 반올림한 값을 더하는 방식이라, 월별 직접입력으로 달마다 값을 다르게 두면 누계에도 그대로 반영됩니다.

✓은 해당 월의 자료가 있다는 뜻이며, 실제 값이 맞는지까지 확인해주지는 않습니다. 빈칸(●)이 있으면 그 달은 누계 계산에서 제외됩니다.

2 기준월 선택 및 출력

인쇄는 A4 가로 1장 고정입니다. 인쇄 대화상자에서 "배경 그래픽"을 켜야 노란 음영이 함께 나옵니다. 엑셀 저장은 두 가지입니다 — 서식 포함은 셀 병합·테두리(실선/점선/이중선)·노란 음영·열 폭·인쇄 설정까지 통계대장 모양 그대로 만들고(인터넷 연결 필요), 값만은 병합과 열 폭만 넣은 가벼운 파일로 만듭니다.

이 달 관내 열람자 배율: - 이 달 이용자료 관내추정 배율: -

두 배율 모두 대출인원(또는 대출건수)에 곱해 관내 이용 규모를 추정하는 값입니다. 적용 방식(고정·미적용·월별 직접입력)과 기본값은 ①단계 → 환경설정 탭에서, 월별 값은 ①단계 → 월별 수기입력에서 정합니다.

월간 개관 일수 : 일
1. 장서현황 기준
2. 이용자 현황

관내(열람자)는 실측치가 아니라, 관외 대출 인원수 × 배율(①단계 환경설정에서 정한 방식·값)로 추정한 값입니다. DLS는 열람만 한 이용자를 별도로 집계하지 않아, 통계대장에서는 이 방식으로 추정합니다. 누계는 매달 반올림한 값을 그대로 더합니다.

3. 이용자료 현황

관내는 관외대출 합계 × 배율(①단계 환경설정에서 정한 방식·값)로 추정한 값이며, 실측이 아닙니다. 누계는 매달 반올림한 값을 그대로 더합니다(배율이 달마다 다를 수 있기 때문).

4. 학교도서관활용수업 및 활용프로그램

이 항목은 DLS 통계 메뉴에 없거나(행사·자원봉사·기타업무) DLS 기능은 있어도 이 학교 계정에는 기록이 없는(도서관활용수업) 것으로 확인되어, 위 "① 데이터 입력 → 월별 수기입력"에서 직접 입력한 값을 사용합니다.

5. 기 타

학교·학년도에 상관없이 그대로 쓸 수 있습니다. 업로드한 DLS 반출 파일과 입력한 내용은 서버로 전송되지 않고 이 브라우저 안에서만 처리되며, 데이터와 환경설정은 이 브라우저(로컬 저장소)에 자동 저장됩니다. 다른 PC로 옮기거나 백업하려면 "설정·입력값 저장(JSON)"을 이용하세요. 반올림은 엑셀 ROUND()와 같은 사사오입(0.5는 항상 올림)입니다. "예시 데이터로 미리보기"의 숫자는 실제 학교 자료가 아니라 화면 확인용으로 임의로 만든 값이며, "전체 초기화"로 언제든 지울 수 있습니다.
